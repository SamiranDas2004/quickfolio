# Testing Payment APIs with Postman

## Prerequisites
1. Make sure your backend is running on `http://localhost:8000`
2. Have Razorpay test credentials in your `.env` file:
   ```
   RAZORPAY_KEY_ID=your_test_key_id
   RAZORPAY_SECRET_KEY=your_test_secret_key
   ```

## API Endpoints

### 1. Create Order (Initiate Payment)

**Endpoint:** `POST http://localhost:8000/api/payment/create-order`

**Headers:**
```
Content-Type: application/json
```

**Body (raw JSON):**
```json
{
  "amount": 500,
  "plan_name": "Pro"
}
```

**Expected Response:**
```json
{
  "order_id": "order_xxxxxxxxxxxxx",
  "amount": 50000,
  "currency": "INR",
  "key_id": "rzp_test_xxxxxxxxxxxxx"
}
```

**Notes:**
- Amount is in rupees (will be converted to paise internally)
- Save the `order_id` for the next step

---

### 2. Verify Payment

**Endpoint:** `POST http://localhost:8000/api/payment/verify-payment`

**Headers:**
```
Content-Type: application/json
```

**Body (raw JSON):**
```json
{
  "razorpay_order_id": "order_xxxxxxxxxxxxx",
  "razorpay_payment_id": "pay_xxxxxxxxxxxxx",
  "razorpay_signature": "generated_signature_hash",
  "user_id": "your_user_id_here"
}
```

**Expected Response (Success):**
```json
{
  "success": true,
  "message": "Payment verified and user upgraded to premium",
  "user_type": "premium"
}
```

**Expected Response (Failure):**
```json
{
  "detail": "Invalid payment signature"
}
```

**Notes:**
- For testing, you'll need actual Razorpay test payment credentials
- The signature is generated by Razorpay after successful payment
- Get `user_id` from your database or signup response

---

### 3. Get Subscription Status

**Endpoint:** `GET http://localhost:8000/api/payment/subscription-status/{user_id}`

**Example:** `GET http://localhost:8000/api/payment/subscription-status/123e4567-e89b-12d3-a456-426614174000`

**Headers:**
```
Content-Type: application/json
```

**Expected Response:**
```json
{
  "type_of_user": "premium",
  "subscription_date": "2024-01-15T10:30:00"
}
```

**Endpoint:** `POST http://localhost:8000/api/auth/signup`

**Body:**
```json
{
  "username": "testuser",

  "password": "testpass123",
  "name": "Test User"
}
```

**Save the user ID from response**

**Body:**

```json
  "amount": 500,

```

**Save the `order_id` from response**

### Step 3: Simulate Payment (For Testing)

Since you can't complete actual Razorpay payment in Postman, you have two options:

#### Option A: Use Razorpay Test Mode
1. Go to Razorpay Dashboard (test mode)
2. Use test card: `4111 1111 1111 1111`
3. Any future expiry date
4. Any CVV

#### Option B: Mock the Verification (Development Only)

Create a test endpoint in your backend:

```python
@router.post("/test-verify-payment")
async def test_verify_payment(user_id: str, db: Session = Depends(get_db)):
    """FOR TESTING ONLY - Remove in production"""
    user = db.query(User).filter(User.id == user_id).first()
    if not user:
        raise HTTPException(status_code=404, detail="User not found")
    
    user.type_of_user = "premium"
    user.subscription_date = datetime.utcnow()
    db.commit()
    
    return {
        "success": True,
        "message": "User upgraded to premium (TEST MODE)",
        "user_type": "premium"
    }
```

**Test Endpoint:** `POST http://localhost:8000/api/payment/test-verify-payment?user_id=YOUR_USER_ID`

## Postman Collection Setup

### Create Environment Variables
1. Click "Environments" in Postman
2. Create new environment "QuickFolio Local"
3. Add variables:
   - `base_url`: `http://localhost:8000`
   - `user_id`: (set after signup)
   - `order_id`: (set after create order)

### Use Variables in Requests
- URL: `{{base_url}}/api/payment/create-order`
- Body: `"user_id": "{{user_id}}"`

## Common Issues & Solutions

### Issue 1: "Invalid payment signature"
**Solution:** This is expected in Postman testing. Use the test endpoint or complete payment through frontend.

### Issue 2: "User not found"
**Solution:** Make sure you're using a valid user_id from your database.

### Issue 3: CORS errors
**Solution:** Add `http://localhost:3000` to CORS origins in backend.

### Issue 4: Razorpay credentials not working
**Solution:** 
- Check `.env` file has correct test credentials
- Restart backend server after updating `.env`
- Verify credentials in Razorpay dashboard
