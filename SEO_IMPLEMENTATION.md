## 📝 Content Guidelines

### Title Tags
- Keep under 60 characters
- Include primary keyword
- Make it compelling
- Unique for each page

### Meta Descriptions
- 155-160 characters
- Include call-to-action
- Use active voice
- Include primary keyword naturally

### Headings
- One H1 per page
- Logical hierarchy (H1 → H2 → H3)
- Include keywords naturally
- Descriptive and clear
